# Changelog

## 0.1.0 Beta 3 (build 1056)

- JIT setup recovers from `BadBuildManifest` by downloading the Developer Disk
  Image again and retrying once.
- Library navigation, background media and settings appearance updates.
- Cover artwork display in the carousel.
- The cover upscaling model is no longer bundled. It can be downloaded from
  Graphics settings or imported from a file.
- Setup opens in full screen on iPhone and iPad.
- Internal test tooling and unused code were removed from the app and the
  renderer.
